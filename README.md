# boardgame
군대에서 한 번 도전하는 웹 멀티 보드게임

현재 구현상태 
1. 멀티서버 구현
2. 주사위 굴리기/보드 구현
3. 턴제 구현
4. 유저 구별을 위한 말 위 아이디 추가
    ㄴ prompt형태로 입장할 때 입력하는 것이 아닌, 사이트를 처음 켤 때 이름을 입력하도록 수정해야함.
5. 땅구매, 통행료 지불기능
6. 파산기능
7. 이동시 한칸한칸 이동
8. 한 바퀴 돌 때마다 월급 기능
9. 무인도 기능
10. 세계일주 기능
11. 사회복지기구

구현해야할 것
1. UI깔끔하게
2. 방 개설 및 참가 기능
3. 캐릭터 선택 / 꾸미기 기능
4. 승리시 계정에 돈 추가(DB필요)

수정해야할 사항
1. 세계일주를 통해서 다른 칸으로 이동할 경우, 빈땅이면 구매, 상대땅이면 통행료 지불 등이 안됨.
    ㄴ dice-result에 있는 땅 구매 confirm로직과 서버의 buy-land socket을 병합 필요.
