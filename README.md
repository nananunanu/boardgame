1. 멀티서버 구현
2. 주사위 굴리기/보드 구현
3. 턴제 구현
4. 유저 구별을 위한 말 위 아이디 추가
    ㄴ prompt형태로 입장할 때 입력하는 것이 아닌, 사이트를 처음 켤 때 이름을 입력하도록 수정해야함.
5. 땅구매, 통행료 지불기능
6. 파산기능
7. 이동시 한칸한칸 이동
8. 한 바퀴 돌 때마다 월급 기능
9. 무인도 기능
10. 세계일주 기능
11. 사회복지기구
12. 맵 중앙 주사위 추가
13. 주사위 굴리기 버튼 디자인 및 기능 개선
14. confirm -> 커스텀 모달로 변경

수정해야할 사항
-세계일주 시 주사위를 한번 더 굴리는 문제 수정해야 함
-게임끝나고 다시 시작하면 초기화는 잘 되는데 턴이 안돌아옴
-땅/건물 구매 로직에 요청하는 유저가 실제 턴의 유저인지 확인하는 코드 추가 - 수정 함
-국세청에서 세금납부하면 100%납부가 안되고 조금만 됨
